# Mahesha S — Personal Portfolio

A simple, responsive professional portfolio built as **one HTML file**, with no paid tools, frameworks, or installation required.

## Preview on your computer

Open `index.html` by double-clicking it. Your browser will show the site, including the navigation and work filters.

## Publish on GitHub Pages

1. Sign into https://github.com/ (or create a free account).
2. Click **New repository**. Name it **YOUR-EXACT-USERNAME.github.io**, replacing YOUR-EXACT-USERNAME with your GitHub username. Set it to **Public** and create it.
3. Click **Add file → Upload files** in the new repository. Upload `index.html`, `README.md` and `.nojekyll` from this folder. Upload the individual files, **not the ZIP file and not the enclosing folder**.
4. Click **Commit changes**.
5. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then click **Save**.
6. Find the live URL at `https://YOUR-EXACT-USERNAME.github.io/`. It can take up to 10 minutes to appear.

GitHub's official instructions: https://docs.github.com/en/pages/quickstart and https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit the site (no coding background needed)

All content and design is inside `index.html`:

- On GitHub, click `index.html` → pencil icon (Edit this file).
- Use **Ctrl+F** to find a phrase such as `Making complex ideas` or `Happiest Minds` and edit its visible text.
- Click **Commit changes**. GitHub Pages republishes the website automatically.
- Make a backup before large changes.

## Important checks before publication

- Check company names, dates, job titles, metrics and project descriptions for accuracy.
- The approximately **30K→75K** LinkedIn follower achievement was supplied as career background; verify it against screenshots/analytics and clarify attribution/timeframe before public publication.
- The current Happiest Minds job title and starting month are **provisional** and require confirmation.
- Project cards are high-level workstream summaries, **not** independently verified case studies or public work samples.
- Obtain permission before sharing any corporate artwork, internal documents, customer names, analytics, campaign figures, or screenshots.
- Confirm your LinkedIn URL and Tathyasaar URL still work.

## Add your resume later

1. Export your approved resume as `resume.pdf`.
2. Upload `resume.pdf` to the same repository root.
3. In `index.html`, you can add `<a class="btn btn-outline" href="resume.pdf" download>Download resume ↓</a>` inside the hero section's `<div class="actions">`. Do this **only after** uploading the PDF, so the link works.

## Add project case studies later

For each project, document the challenge, your responsibilities, actions, tools, outcomes, and permitted supporting evidence. Don't invent metrics or claim company-wide results as solely your own.

## What is included

- `index.html` — complete responsive website, styles and small interactive scripts
- `.nojekyll` — tells GitHub Pages to serve the static files directly
- `README.md` — this guide

No tracking scripts, third-party fonts or external JavaScript are required. Links to LinkedIn and Tathyasaar are the only external links in the website.
